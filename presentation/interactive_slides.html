Faculty Examination Directory
Viva Voce Defense Anticipated Faculty Q&A

Q1: Why eBPF/XDP instead of DPDK?

DPDK bypasses OS and burns 100% CPU on polling. eBPF collaboratively passes benign packets to OS while dropping malicious packets in nanoseconds.

Q2: Why Generic SKB mode instead of Native Driver?

Virtual interfaces (veth, bridges) require Generic SKB mode. On physical NICs (Intel/Mellanox), exact same C code runs in Native Driver mode.

Q3: How do you handle IP spoofing?

Every container connects to a dedicated point-to-point veth pair. Port-to-MAC bindings prevent cross-namespace spoofing.

Q4: What happens if the Python daemon crashes?

Kernel datapath continues enforcing existing BPF maps indefinitely without dropping connections. Control plane is fully decoupled!

Q5: Why pure Linux netns instead of Docker?

Docker daemons consume 1.5+ GB RAM. Pure netns uses <11 MB RAM for 16 microservices, ensuring reproducible microsecond benchmarking.

Q6: Can this protect against Layer 7 SQLi/XSS?

XDP stops volumetric L2–L4 floods in nanoseconds, shielding L7 WAFs from resource exhaustion so they can inspect deep payloads.
